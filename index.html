นโยบายความเป็นส่วนตัว (Privacy Policy)

อัปเดตล่าสุด: 25 พฤษภาคม 2568

1. ข้อมูลที่เราเก็บ

YaMed เก็บข้อมูลเท่าที่จำเป็นสำหรับการทำงานของแอปเท่านั้น ได้แก่:

  • ข้อมูลยา — ชื่อยา ขนาดยา เวลากิน หมายเหตุ ที่คุณกรอกเอง
  • ประวัติการกินยา — บันทึกว่าวันไหนกินยาครบหรือไม่
  • ข้อมูลตัวตน (เฉพาะเมื่อเข้าสู่ระบบ) — อีเมลและชื่อจาก Google Sign-In เพื่อสำรองข้อมูลบน Cloud
  • ตั้งค่าส่วนตัว — avatar ที่เลือก, ธีมสี, Streak badge

2. วิธีที่เราใช้ข้อมูล

  • แสดงรายการยาและส่งการแจ้งเตือนตรงเวลา
  • คำนวณ Streak เพื่อสร้างแรงบันดาลใจในการกินยาต่อเนื่อง
  • สำรองและซิงค์ข้อมูลข้ามอุปกรณ์ (เฉพาะผู้ใช้ที่เข้าสู่ระบบ)
  • เราไม่ขาย ไม่แชร์ และไม่ใช้ข้อมูลของคุณเพื่อโฆษณา

3. การจัดเก็บข้อมูล

  • บนอุปกรณ์ — ข้อมูลยาและการตั้งค่าถูกเก็บใน AsyncStorage บนอุปกรณ์ของคุณโดยตรง ไม่ผ่านเซิร์ฟเวอร์
  • Cloud (optional) — หากคุณเลือก Sign in ด้วย Google ข้อมูลจะถูกเข้ารหัสและจัดเก็บบน Firebase (Google Cloud) ภายใต้นโยบายความปลอดภัยของ Google

4. การแชร์ข้อมูลกับบุคคลที่สาม

เราไม่แชร์ข้อมูลส่วนตัวของคุณกับบุคคลภายนอก ยกเว้น:

  • Firebase / Google — สำหรับ Authentication และ Cloud Firestore (เฉพาะผู้ใช้ที่เข้าสู่ระบบ) ดูนโยบายของ Google ได้ที่ policies.google.com/privacy
  • กฎหมาย — หากมีคำสั่งทางกฎหมายบังคับให้เปิดเผย

5. การแจ้งเตือน (Push Notifications)

YaMed ขอสิทธิ์ส่ง Push Notification เพื่อเตือนให้คุณกินยาตรงเวลา คุณสามารถปิดการแจ้งเตือนได้ตลอดเวลาในการตั้งค่าระบบของอุปกรณ์ การปิดแจ้งเตือนไม่มีผลกระทบต่อข้อมูลยาของคุณ

6. ข้อมูลสุขภาพ

YaMed ไม่ได้เป็นแอปทางการแพทย์ ข้อมูลยาและการแจ้งเตือนในแอปมีไว้เพื่อช่วยให้คุณจำกินยาเท่านั้น ไม่ใช่คำแนะนำทางการแพทย์ กรุณาปรึกษาแพทย์หรือเภสัชกรสำหรับข้อมูลยาที่ถูกต้อง

7. สิทธิของคุณ

  • ลบข้อมูล — คุณสามารถลบยาทั้งหมดในแอปได้ตลอดเวลา หรือถอนการติดตั้งแอปเพื่อลบข้อมูลบนอุปกรณ์
  • ลบข้อมูล Cloud — ส่งคำขอมาที่ manglnwza888@gmail.com เพื่อลบข้อมูลจาก Firebase
  • ส่งออกข้อมูล — ติดต่อเราหากต้องการสำเนาข้อมูลของคุณ

8. ความปลอดภัย

เราใช้ Firebase Security Rules เพื่อให้มั่นใจว่าผู้ใช้แต่ละคนเข้าถึงได้เฉพาะข้อมูลของตัวเอง ข้อมูลทั้งหมดที่ส่งระหว่างแอปและ Firebase ถูกเข้ารหัสด้วย HTTPS/TLS

9. เด็กและผู้เยาว์

YaMed ไม่ได้ออกแบบมาสำหรับเด็กอายุต่ำกว่า 13 ปี หากพบว่ามีการเก็บข้อมูลจากเด็กโดยไม่ได้รับความยินยอม เราจะลบข้อมูลนั้นทันที

10. การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลงนโยบายความเป็นส่วนตัวที่มีนัยสำคัญ เราจะแจ้งให้ทราบผ่าน App Store / Play Store หรืออัปเดตวันที่ด้านบนของหน้านี้
